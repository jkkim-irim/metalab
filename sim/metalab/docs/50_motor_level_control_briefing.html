2. 엔진별 구현

엔진한 일특이사항
newton 내장 PD off → 물리스텝마다 warp 커널로 토크 주입 CUDA graph 캡처 → CPU 개입 0
genesis 내장 PD off → 같은 newton 커널을 어댑터(~30줄)로 실행 스텝 루프 재구성. warp = 필수 의존성
  • warp = 파이썬으로 GPU 커널을 쓰는 라이브러리. 같은 수식을 torch로 짜면 50.65 ms/step, warp는 12.75 ms(2048 env) → warp만 남김.
  • 코드 한 벌 공유라 구현이 갈라질 수 없고, numpy 정답지로 오차 1e-9 고정(테스트 11개).
  • 제어주기로만 돌리면 가벼운 축이 발진(29 rad/s) → 물리스텝마다 재계산 필수.

4. 다른 시뮬레이터 이식성

조건은 둘 — ① 관절 상태가 GPU에 있고 복사 없이 접근 가능, ② 토크 직접 주입 가능. genesis는 taichi 기반인데도 newton 커널이 그대로 돌았습니다.
